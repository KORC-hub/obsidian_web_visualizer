# Artefactos de administration de software

Estado: Sin empezar

Es necesario que durante cada una de las fases del desarrollo de un sistema, se pueda desarrollar una serie de documentos que permitan evaluar y medir el proceso del proyecto.

Para hacer manejable el desarrollo de un sistema completo, los artefactos se dividen en conjuntos de artefactos que están relacionados y en un formato uniforme.

Pero que es un artefacto, un artefacto son elementos tangibles, que son producidos durante la creación de un proyecto. Su objetivo principal es el de capturar y mostrar la información de los proyectos. Los artefactos se dividen en varias categorías como:   

- Documentos: Pieza de información.
- Modelo: representaciones graficas.
- Elementos: características, funcionalidades o elementos dentro de un modelo. (subclases o subsistemas).

Para permitir que el desarrollo del proyecto de software sea administrable, los artefactos se organizan en diferentes sets, los cuales corresponden a cada una de las etapas del desarrollo de sistemas.

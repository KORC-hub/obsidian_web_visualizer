# Documentación de Software

Estado: Sin empezar

reunir y procesar documentos sobre un tema especifico con el fin de difundir un resultados

- Del contrato con el cliente para el sistema
- tipo del sistema que se esta desarrollando
- de la vida útil prevista
- de la cultura de la empresa
- del tamaño de la empresa que desarrolla el sistema
- development schedule

Se debe de escribir como lo esta observando el lector:

- No ser redundante
- y ser claro

Documentación interna: Desarrolladores 

Documentación externa: reqisitos, diseños.

Plan de desarrollo(SDP: software development Plan)

- matriz de riesgos
- que metodología se va a utilizar
    - el tiempo que se va a realizar la metodología
- Licencias, maquinas
- Gantt Proyect

Software Requirements Specification (SRS)

Software Design Documentation (SDD)

- Prototipo
- Modelo entidad-relacion
- Diagrama de clases
- Arquitectura
    - Cliente
    - CLiente Servidor

Documento Tecnico

Software Test Documents/Plan (STD/P)

- Modulo que se esta probando

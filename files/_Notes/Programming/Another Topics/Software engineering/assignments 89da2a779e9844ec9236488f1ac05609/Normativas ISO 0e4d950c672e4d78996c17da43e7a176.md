# Normativas ISO

Estado: Sin empezar

1. ISO/IEC 25000: Esta norma establece los requisitos y recomendaciones para la evaluación de la calidad del software, incluyendo características como la funcionalidad, fiabilidad, usabilidad, eficiencia y mantenibilidad.
2. ISO/IEC 27001: Se centra en la seguridad de la información, incluyendo la gestión de riesgos de seguridad relacionados con el software y los sistemas de información.
3. ISO/IEC 9126: Esta norma, aunque fue sustituida por la ISO/IEC 25000, aún es relevante en algunos contextos. Se centra en la calidad del software y establece un modelo de calidad con características como la funcionalidad, fiabilidad, usabilidad, eficiencia, mantenibilidad y portabilidad.
4. ISO/IEC 12207: Define un marco de procesos para el ciclo de vida del software, lo que incluye actividades como la adquisición, suministro, desarrollo, operación y mantenimiento del software.
5. ISO/IEC 90003: Esta norma proporciona directrices para la aplicación de la norma ISO 9001 en el desarrollo, suministro y mantenimiento del software.

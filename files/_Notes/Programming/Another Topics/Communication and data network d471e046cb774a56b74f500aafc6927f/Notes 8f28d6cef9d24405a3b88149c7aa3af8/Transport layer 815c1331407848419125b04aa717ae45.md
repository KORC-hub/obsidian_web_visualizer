# Transport layer

Status: Protocols TCP/IP

### UDP (User datagram protocol)

Se utiliza para **transmitir datagramas de forma rápida en redes IP** y funciona como una alternativa sencilla y sin retardos, pero menos segura del protocolo TCP El UDP es más rápido pero menos fiable que el TCP). Se usa principalmente para consultas DNS, conexiones VPN y para el streaming de audio y vídeo.

Un ordenador no transferirá realmente paquetes de datos al otro hasta que no se haya completado el protocolo de enlace. Las comunicaciones UDP no pasan por este proceso. En su lugar, un ordenador simplemente puede empezar a enviar datos al otro:

### TCP (Transmission Control protocol)

El TCP crea una línea de comunicación segura para garantizar la transmisión fiable de todos los datos.

# Communication Methods in Networks

Status: Concepts

Los distintos métodos de comunicación utilizados para transmitir datos entre dispositivos:

| Unicast  | Se envía desde un único remitente **a un único destinatario.** |
| --- | --- |
| Broadcast | Se envía desde un único emisor **a todos los dispositivos conectados a una red.** |
| Multicast | Se envía desde un único emisor **a múltiples destinatarios específicos.** |
| Anycast | Se envía **a la instancia más cercana de un grupo de destinatarios**, optimizando la respuesta |

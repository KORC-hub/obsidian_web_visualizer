# Layer models

Status: Concepts

**Porque utilizar un modelo de capas (estructura modular):** Porque es un tema complejo que involucra equipos con diferencias en software y hardware **(diferentes fabricantes)**, además de que **es mas fácil saber en donde esta el origen del problema**, de h**acer cambios de manera mas gradual y sencilla.** (divide y vencerás)

# Principios del modelo de capas:

- La capa n solo habla con sus vecinas (n + 1 y n - 1), esto no se cumple para la ultima y la primera capa.
- Una interfaz es la comunicación que hay entre las diferentes capas, las interfaces no tiene que ser igual para todas las entidades.
- Cada entidad (de la capa n) habla con su homologa utilizando un protocolo característico, acordado por las entidades (de la capa n) .
- El conjunto de protocolos utilizados en todas las capas se denomina pila de protocolos (protocol stack).

## Diferencias entre el modelo TCP/IP con OSI

| TCP/IP | OSI |
| --- | --- |
| Cuatro capas | Siete capas |
| Sigue un enfoque horizontal sin conexión | Sigue un enfoque vertical |
| La capa de transporte no garantiza la entrega de paquetes | la capa de transporte garantiza la entrega de paquetes |
| La capa de red solo solo proporciona servicio sin conexión (IP). La capa de transporte proporciona conexión (TCP).  | Los servicios sin conexión y orientados a conexión son proporcionados por la capa de red. |
| La fortaleza del modelo de referencia TCP/IP son los protocolos, que se han utilizado mucho durante varios años. | La fortaleza del modelo de referencia OSI es el modelo en sí (excepto las capas de presentación y de sesión), el cual ha demostrado ser excepcionalmente útil para hablar sobre redes de computadoras. |
| Primero llegaron los protocolos (TCP y IP) y el modelo era en realidad
sólo una descripción de los protocolos existentes. El único problema fue que el modelo no encajaba en ninguna otra pila de protocolos. En consecuencia, no era útil para describir otras redes que no fueran
TCP/IP. | Primero se creo el modelo y luego llegaron los protocolos, los protocolos no funcionaron como se esperaba y la Arquitectura OSI fracaso, aunque el modelo no. |
| no distingue entre la capa física y la de enlace de datos. Éstas son completamente distintas. La capa física trata sobre las características de transmisión del cable de cobre, la fibra óptica y la comunicación inalámbrica. La tarea de la capa de enlace de datos es delimitar el inicio y el in de las tramas, además de transmitirlas de un extremo al otro con el grado deseado de confiabilidad. | Si distingue entre la capa física y la de enlace. |

# Un servicio es fiable si:

- se reciben todos los paquetes (no hay paquetes perdidos).
- se reciben sin errores.
- se reciben solo una vez (sin duplicados).
- Se reciben en el mismo orden.

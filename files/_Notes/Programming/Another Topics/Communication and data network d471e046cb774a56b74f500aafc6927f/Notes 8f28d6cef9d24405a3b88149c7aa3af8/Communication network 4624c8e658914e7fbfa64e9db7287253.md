# Communication network

Status: Concepts

Todos los métodos de comunicación tienen tres elementos en común

- Origen o **emisor**
- Destino o **receptor**
- Canal o **medio**

Una red de comunicación es un **grupo de dispositivos** que están **conectados** con el propósito de  **transmitir información y datos  entre diferentes puntos.** Esta red nos da la capacidad de compartir recursos(texto, imágenes, audio, etc.). Los datos se transmiten de un dispositivo a otro a través de conexiones de datos.

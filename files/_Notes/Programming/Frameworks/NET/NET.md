# .NET

.NET proporciona una serie de marcos específicos de la plataforma para la creación de aplicaciones:

- .NET para Android, iOS y MAC
- WinUI 3 (aprovechando el SDK de aplicaciones para Windows).

Todos estos marcos de trabajo tienen acceso a la misma biblioteca de clases base de .NET 6 (BCL). Esta biblioteca proporciona la funcionalidad para crear y administrar recursos

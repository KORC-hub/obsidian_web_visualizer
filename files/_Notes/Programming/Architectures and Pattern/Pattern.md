# Repository

El patron de diseño repository, se basa en la abstracción y encapsulación de la capa de acceso a datos. Proporciona una estructura intermedia que permite interactuar con la capa de acceso a datos y la logica de negocio para facilitar las acciones de un CRUD (Create, Read, Update, Delete). Gracias a este patrón de diseño, es posible realizar una separación de preocupaciones (inversion de dependencias **creo**) que mejora la mantenibilidad del código.

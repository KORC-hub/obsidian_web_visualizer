Next.js es un **framework de React** que facilita la construcción de aplicaciones web listas para producción, que sin necesidad de instalar paquetes adicionales proporciona características como:

- **Routing** (Sistema de enrutamiento automático)
- **API Routes** (Definición de endpoints dentro de la aplicación)
- **Renderizado optimizado** (SSR y SSG)
- **Data Fetching** (Manejo eficiente de datos en el servidor o cliente)
- **Styling** (Soporte para CSS, Sass, Tailwind, etc.)
- **Optimización** (Mejor rendimiento con imágenes y fuentes optimizadas)
- **Entorno Dev y Prod** (Sistema de construcción para desarrollo y producción)

## Instalación y Creación de un proyecto

Para iniciar un proyecto de Next.js, se requiere [Node.js](https://nodejs.org/en) y se puede crear con:

```shell
npx create-next-app@latest
```

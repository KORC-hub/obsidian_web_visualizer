## Client-Side Rendering (CSR)

Es el modelo tradicional de React. Todo el código JavaScript se envía al navegador, y el cliente se encarga de renderizar la UI.

## React Components

 es un paradigma en React que permite renderizar componentes en el servidor antes de enviarlos al cliente.

- Virtual DOM

## JSX

```bash
npm init -y
npm create vite@latest  
```

Un componente es  una funcion que retorna elementos, y un elemento es lo que renderiza React

- appear -> parecer (dar la impresión de)
- resemble -> parecerse a
- seem -> parecer (según percepción)

composition: 
- consist of -> consistir en (estar compuesto por)
- contain -> contener
- have -> tener (como parte de algo)

- come from -> provenir de
- concern -> concernir / tratar sobre
- cost -> costar
- fit -> quedar bien / ajustar
- suit -> sentar bien / convenir

existence:
- be -> ser / estar
- exist -> existir

knowledge:
- forget -> olvidar
- know -> saber / conocer
- realise -> darse cuenta (de)
- understand -> entender / comprender

- hate -> odiar
- like -> gustar
- love -> encantar / amar
- prefer -> preferir

- need -> necesitar
- want -> querer
- wish -> desear


The anatomy of a prompt:

- Clear -> provide relevant context
- Specific -> avoid unnecessary information
- Open-ended -> surface non-obvious insights

what to avoid:

- Overloading
- Ambiguity -> vague prompts
- Over-complication -> using jargon

Limitations

- Biases -> the model presents steotypes or missinformation
- Hallucinations -> the model confidently state incorrect information
- Overfitting -> the model is only as good as the data it's trained on.


SALT Framework:

- Style -> define the framework
- Audience -> tailoring the context
- Lenght -> brevity or depth
- Tone -> mood and feel

The four cornerstones of evaluation

LARF:

- Logical consistency
- Accuracy
- Relevence
- Factual correctness

User Markdown to estructure the prompt, using:

- Bold 
- quotietion marks 
- delimiter (---)

Training techniques:
- Zero-shot -> without example
- One-shot -> one example
- Few-shot -> more than one example

Personal-problem-solution framework
- Instructions
- Persona
- Output format
- Context
- Example

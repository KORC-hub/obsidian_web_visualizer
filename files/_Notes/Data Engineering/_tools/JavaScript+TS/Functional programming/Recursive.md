# Recursive

Status: Functions

Una función se puede llamar a sí misma, siempre y cuando no lo haga tan a menudo que desborde la **pila de llamadas**, hay que tener en mente que al momento de utiliza funciones recursivas estas suelen ser mas lentas que utilizar un bucle normal, por que **recorrer un simple bucle suele ser más económico que llamar a una función múltiples veces.**

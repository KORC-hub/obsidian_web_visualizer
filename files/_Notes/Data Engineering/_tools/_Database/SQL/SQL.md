# SQL 

> [!warning]
> Todos los ejemplos y funcionalidades se explican en base a Transact-SQL (SQL Server). Es posible que algunas cosas no estén disponibles en otros SGBD.

## Temas

1. [[DDL]] — Data Definition Language (**CREATE**, **ALTER**, **DROP**, **RENAME**, **COMMENT**)
2. [[DCL]]— Data Control Language (**GRANT**, **REVOKE**, **DENY**)
3. [[DML]] — Data Manipulation Language (**INSERT**, **UPDATE**, **DELETE**, **TRUNCATE**)
4. [[DQL]] — Data Query Language (**SELECT** y cláusulas asociadas)
5. [[Data-types]] — Tipos de datos (numéricos, texto, fecha) comparados entre SGBD
6. [[Functions]] — Funciones agregadas, matemáticas, de fecha, conversión y string
7. [[Subqueries]] — Subconsultas (ANY/ALL/SOME, IN, EXISTS)
8. [[JOINS]] — JOINs, UNION, EXCEPT, INTERSECT
9. [[Stored-procedures-and-functions]] — Funciones vs. procedimientos almacenados (Views quedó pendiente, ver nota en el archivo)
10. [[Triggers]] — Triggers
11. [[views|Views]]

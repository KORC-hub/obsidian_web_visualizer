# Navigation

- `pwd` : Muestra ruta actual
- `cd ..` : Cambiar al directorio padre
- `cd [path]` : Cambiar a una carpeta
- `ls` : Muestra todos los archivos de la carpeta
    - `-l` : ver los archivos en lista
    - `-h` : ver las unidades (K, M)
    - `-a` : ver todos los archivos (también ocultos)

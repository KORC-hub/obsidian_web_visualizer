# Crear

- `mkdir <dir_name>` : Crea una carpeta
- `touch document.txt` : Crea un archivo
- `nano document.txt` : Crea un archivo y permite modificarlo en el editor nano

# Eliminar


- `rm document.txt` : Elimina un archivo
- `rm -rf directory` : Elimina una carpeta
# Mover o Editar

- `mv document1.txt directory` : Mueve un archivo a una carpeta
- `mv old_name.txt new_name.txt` : Cambiar el nombre o extensión a un archivo

# Dictionary of terms

# Programming

**■** Framework: proporciona muchas herramientas para poder desarrollar aplicaciones más complejas

**■** librería: te proporciona herramientas para solucionar un problema en específico

**■** Refactorizar: Cambiar la estructura interna pero sin alterar el comportamiento externo

KISS = (Keep It Simple, Stupid)

DRY = (Don't Repeat Yourself)

YAGNI = (You Aren’t Gonna Need It)

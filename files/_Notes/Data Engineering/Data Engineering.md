# Funciones

Realmente no tiene mucho es pura inforamcion, esto es lo que dice en funciones a realizar:

• Apoyar en la ingesta y estructuración de datos: Colaborar en la recopilación, limpieza y organización de datos provenientes de diversas fuentes (plataformas de mercadeo, bases de datos, APIs ([[JavaScript+TS]]), etc.).

• Diseño de flujos ETL: Asistir en la creación y mejora de flujos de datos (ETL/ELT) para estructurar la información y dejarla disponible en las bases de datos de análisis, mediante diferentes tecnologías y lenguajes de programación como Python y SQL

• Automatización de procesos operativos: Identificar tareas manuales repetitivas en el manejo de datos y participar activamente en su automatización para reducir tiempos de procesamiento y errores humanos.

• Apoyar en la supervisión de las tareas automatizadas existentes para asegurar que se ejecuten correctamente y reportar fallas de manera oportuna.

• Implementar validaciones y reglas de negocio básicas para asegurar que la información entregada a los equipos de BI y Ciencia de Datos sea confiable, precisa y esté actualizada.

• Trabajar de la mano con analistas de BI y científicos de datos para entender sus necesidades de información y facilitarles el acceso a las tablas o vistas requeridas

• Documentar los flujos de datos, fuentes y automatizaciones desarrolladas durante la práctica para asegurar la continuidad del conocimiento en el equipo.
